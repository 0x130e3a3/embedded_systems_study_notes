### usb主机如何识别到usb设备被插入了?

## USB2.0协议中6种设备状态
1. 连接状态attached
    物理连接已建立。
2. 上电状态powered
    设备从 VBUS 获得供电。
    设备把 1.5kΩ 上拉电阻接到 D+ 或 D- 上
    此时主机通过检测电平变化得知设备被插入
    主机发送复位信号，D+、D- 同时拉低，形成 SE0，持续至少 10ms。
3. 默认状态default
    主机复位后，设备处于地址 0
4. 地址状态address
    主机分配了非零地址。
    usb设备地址是主机分配的
5. 配置状态configured
    主机发送 SET_CONFIGURATION 后进入该状态。
6. 挂起状态suspend
    总线空闲一段时间后进入低功耗状态。


## 展开讲下空闲,插入和拔出时的电平状态和变化
1. 对于usb2.0的低速设备
    host的D+和D-各有一个15K的下拉电阻，空闲时两条线都是低电平
    device的D-有一个1.5K的上拉电阻,设备插入后,D-数据线被拉高到约 3V
    主机看到 D- 被拉高，判断为低速。
2. 对于usb2.0的全速设备
    host的D+和D-各有一个15K的下拉电阻，空闲时两条线都是低电平
    device的D+有一个1.5K的上拉电阻,设备插入后,D+数据线被拉高到约 3V
    主机看到 D+ 被拉高，判断为全速。
3. 对于usb2.0的高速设备
    host的D+和D-各有一个15K的下拉电阻，空闲时两条线都是低电平
    device的D+有一个1.5K的上拉电阻,设备插入后,D+数据线被拉高到约 3V
    主机看到 D+ 被拉高，判断为全速。
    所以高速设备会被先识别为全速设备
    之后通过Chirp K/J 握手协议,再被确认为高速设备
    然后会设备将1.5k的上拉电阻断开启用 45Ω 高速终端电阻
    另外高速设备通信用的是电流模式,差分信号幅值约 400mV 级别
    高速设备拔出后，主机端终端电阻从 22.5Ω 变为 45Ω，差分信号幅值从约 400mV 升至约 800mV。Hub 在每个 MicroSOF 包结束时检测，若差分幅值 ≥ 625mV 则判定设备断开。
4. 对于usb3.0的设备
    会先走 USB 2.0 的 D+/D- 枚举流程
    同时主机在 SuperSpeed 差分对上执行 Rx Detect
    主机通过检测 TX 线上电压上升/充电速率或 RC 时间常数的变化，判断对端接收终端是否存在。
